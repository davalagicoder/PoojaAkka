🎂 Birthday Surprise for Akkavva ❤️

A beautiful birthday surprise website created with love!

💝 About the Project

This is a special interactive birthday website created for Akkavva using HTML, CSS, and JavaScript. It contains six beautiful surprises, heartfelt messages, personal memories, birthday wishes, and animations.

✨ Features

  • 🎁 Beautiful birthday welcome screen
  • 🎂 Six interactive birthday surprises
  • 📸 Personal photo gallery
  • 💌 Special birthday letter
  • 🌸 Beautiful memory section
  • 🌟 Interactive birthday wish
  • 🎀 Special grand finale
  • 💖 Floating hearts and sparkle animations
  • 📊 Surprise progress counter
  • 🔁 Restart surprise option

🛠️ Technologies Used

  • HTML5
  • CSS3
  • JavaScript

🚀 How to Run

  1. Clone or download this repository.
  2. Open the project folder.
  3. Open index.html in your browser.
  4. Click on Start Your Surprise.
  5. Enjoy all six birthday surprises!
