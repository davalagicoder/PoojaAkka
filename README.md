# 🎂 Birthday Surprise for Akkavva ❤️

A special and interactive birthday surprise website created with love using **HTML, CSS, and JavaScript**.

This website is designed to make Akkavva's birthday memorable through six beautiful surprises, lovely messages, special memories, and animations.

## 🌸 About the Project

This project is a personalized birthday greeting website where users can explore six different surprises one by one. Each surprise contains a special message, memory, or interactive experience.

The website ends with a heartfelt birthday message expressing love, care, and the special bond between a brother and sister.

## ✨ Features

- 🎁 Beautiful birthday welcome screen.
- 🎂 Six interactive birthday surprises.
- 📸 Photo gallery to display memorable moments.
- 💌 Personalized birthday letter.
- 🌸 Special memory section.
- 🌟 Interactive birthday wish feature.
- 🎀 Special final birthday surprise.
- 💖 Floating heart and sparkle animations.
- 📊 Surprise progress counter.
- 🔁 Option to restart the birthday surprise.
- 📱 Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure and content of the website.
- **CSS3** – Provides styling, colors, animations, and responsive layout.
- **JavaScript** – Handles interactive buttons, navigation between surprises, progress tracking, and animations.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click on **Start Your Surprise**.
5. Explore all six birthday surprises.
